# Внесение вклада в Reserve Station

Спасибо за ваш вклад в Reserve Station.
При внесении вклада обязательно следуйте нашим [кодовым соглашениям](https://docs.spacestation14.com/en/general-development/codebase-info/codebase-organization.html) и [руководству по PR](#пулл-реквесты).

> [!IMPORTANT]
> Поскольку это **хард-форк**, любой код, взятый из другого апстрима, не может быть напрямую замержен сюда, а должен быть перенесен.

## Комментарии

Все добавления нового контента должны делаться в подпапках `_Reserve`.

Все изменения **вне** папок `_Reserve` должны обозначаться комментариями, чтобы было легче понять, где изменения апстрима, а где - наши.

### Примеры

**Yaml**/**Toml**/**Python** (.yml, .toml, .py) - в зависимости от изменений можно оставить комментарий напротив однострочного изменения, либо обхватить ими многострочное:

```yml
  state: new  # Reserve edit: <Название ПРа> - <опциональное пояснение>

  # Reserve edit start: <Название ПРа> - <опциональное пояснение>
  color: white
  shader: unshaded
  # Reserve edit end: <Название ПРа>
```

**C#** (.cs) - правила такие же:

```cs
  return;  // Reserve edit: <Название ПРа> - <опциональное пояснение>
```

**Xaml**/**Xml**/**Mardown** (.xaml/.xml/.md) - в xaml и xml написать комментарии выйдет только между/снаружи тегов:

```xml
  <!-- Reserve edit: <Название ПРа> - <опциональное пояснение> -->
```

## Пулл-реквесты

Все изменения в этот репозиторий должны вноситься в виде пулл-реквестов (PR).

Подсказки по оформлению описания ПРа:

- `<!-- Текст между стрелками - это комментарии - они не будут видны в вашем ПРе. -->`;
- Вы сожете составлять чек-листы для заполнения по ходу разработки ПРа: `- [x] Я сделаю хорошее`;
- Не забывайте добавлять скриншоты и видео в описание, чтобы было легче визуально понять, что из себя представляет ваше изменение.

Больше о Markdown правилах и подобных приёмах можно почитать тут: [Базовый синтаксис написания и форматирования](https://docs.github.com/ru/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax)

### Изменения

В блоке "**Изменения**" вы можете написать список изменений, который будет автоматически добавлен в игру, когда ваш PR будет принят.
Для записей в списке изменений есть 4 значка: add, remove, tweak, fix. Думаю, вы сможете разобраться с остальным.

Вы можете поставить свой ник после символа :cl:, чтобы изменить ник, который будет отображаться в журнале изменений (в противном случае будет использоваться ник вашего аккаунта GitHub). Например: ":cl: Ceterai".

Как правило, в журналы изменений следует помещать только то, что действительно важно игрокам. Вещи вроде "Рефактор системы X, но изменений вы не увидите" - не должны быть в журнале изменений, эти изменения обычные игроки не смогут заметить.

При написании списка изменений НЕ считайте суффикс типа записи (например, add) "частью" предложения:
Плохо: - add: Хирургия может вырезать яйца.
Хорошо: - add: Добавлена хирургическая операция, которая позволяет вырезать яйца.

Не забудьте убрать стрелки комментариев, чтобы список изменений отображался, если вы считаете, что он нужен.

Пример:

```
:cl:
- add: Добавлено веселье.
- remove: Удалено веселье.
- tweak: Изменено веселье.
- fix: Исправлено веселье.
```
